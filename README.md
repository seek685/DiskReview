# DiskReview 磁盘清理助手

这是 Windows 10/11 上的本地磁盘占用审查工具，使用 Python 3.11+ 标准库和 Tkinter。它只检查文件元数据，不读取文件正文，不连接网络。它不能自动判断所有文件是否无用；所有清理均需手动勾选和确认。

图形界面默认将完整路径报告和操作日志保存在 `%LOCALAPPDATA%\DiskReview\reports`，不写入源码目录。手动导出默认只含类别、大小和数量；明确选择包含完整路径后才会导出应用名称、路径和错误详情。匿名汇总仍可能反映软件类别和磁盘使用量，分享前请查看。旧版在源码目录生成的 `reports/` 仍留在本机，已被 Git 忽略；不要通过压缩包或 `git add -f` 分享。

安装带 Tcl/Tk 的 Python 3.11+ 后双击 `start.cmd`，或运行 `py -3 app.py`。自动识别本机固定磁盘、当前用户的 AppData 和系统目录，不依赖特定盘符。工具不会自动删除，也没有安装计划任务。

## C 盘空间诊断

双击 `启动C盘诊断.cmd`，或运行 `py -3 app.py --c-start`，打开并分析系统盘。也可在主窗口点“C 盘空间诊断”，再点“分析 C 盘”。“C 盘”入口实际使用 Windows 系统盘，不依赖安装位置。

“目录占用排行”把小文件累计到目录总量，支持逐层展开，按大小排列；单个达到 100 MB 的大文件也会列出。这里的统计不受主窗口 500 MB 大文件阈值影响。父目录包含子目录，不可重复相加；每层最多展示最大的 500 项，目录总大小仍包含全部项目。

选中项目查看用途、处理影响和建议。明确识别的缓存可在确认后清理；聊天记录、下载资料、模型和虚拟磁盘需要先确认或备份；软件本体通过应用设置卸载；系统目录、分页和休眠文件交给 Windows 管理。目录名为 `cache` 不代表整个目录都能删除。不要手动删除 WinSxS 和 Windows Installer 缓存。

“清理建议”列出已识别的缓存、更新暂存和回收站位置，避免父子目录重复统计。建议大小不是保证可释放的空间；停止后的部分结果不会生成清理建议。点“查看 C 盘可清理文件…”会重新扫描系统盘，缓存显示门槛调整为 1 MB，沿用当前保留天数，所有项目仍默认未勾选。新增浏览器多个配置的网页/图形缓存，以及常见编辑器界面缓存、uv 下载缓存和 DirectX 缓存规则；不处理整个账号配置或工程目录。

扫描只读，跳过识别出的目录链接、云占位符和无法读取的内容，并注明统计限制。逻辑文件大小与系统报告已用空间口径不同，硬链接、压缩、系统保留空间和访问权限都会影响结果，不能用两者之差推断“隐藏垃圾”。默认“全部回收站”要清空后才释放空间；选择“推荐方式”时，勾选并再次确认的缓存和更新包会永久清理。

命令行也支持只读占用分析：

```
py -3 app.py --scan space --output space-summary.json
py -3 app.py --scan space --root C:\ --output space-summary.json
```

默认只导出容量和文件数量汇总，未指定输出路径时保存为报告目录内的 `latest-space-summary.json`，与缓存扫描清单分开。`--include-private-paths` 额外导出目录和大文件路径及错误示例。报告保留在本机，分享前请检查。系统清理依据：[Microsoft 磁盘空间清理说明](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)、[WinSxS 清理](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/clean-up-the-winsxs-folder?view=windows-11)、[Windows Installer 缓存保护](https://learn.microsoft.com/en-us/troubleshoot/windows-client/application-management/missing-windows-installer-cache)。

## 主窗口扫描与清理

1. 点“快速扫描缓存”，或“扫描本地磁盘”。全盘扫描会查找较大的普通文件和受保护文件，可能需要几分钟。
2. 点击一行，查看完整路径、大小、用途和建议。说明来自明确的缓存目录规则、文件名和扩展名，不代表已经证明文件没用；不明文件只展示。
3. 点击第一列方框勾选。所有项目默认不勾选；主窗口中的系统文件、聊天数据库、模型、虚拟磁盘和软件本体不可勾选。完整应用数据可在新增的“应用数据 / 占用”窗口中单独查看、确认回收。
4. 选择处理方式，点窗口顶部的“清理 / 删除勾选项”，核对弹窗后执行。未勾选可处理项目或扫描尚在进行时，按钮显示灰色。关闭相关软件后通常能清理更多文件。

默认参数：缓存目录至少 100 MB、单个大文件至少 500 MB，保留最近 7 天修改的文件。可自行调整，修改后重新扫描。“可处理”仅包括满足保留天数的文件；0 天也不等于自动选择。

“全部回收站”为默认选项，不会立即释放磁盘空间；无法回收时报告失败，不会改成永久删除。可另选“推荐方式”，永久清理已勾选并确认的缓存和更新包，把其他文件移到回收站。也可以选择“永久删除”。永久删除不能从回收站恢复。

主窗口会重新核对文件身份、大小和修改时间；发生变化、存在多个硬链接、目录链接/云文件占位符、访问受限或删除时正在占用的文件会跳过。不会自动关闭软件，不会取得文件所有权或修改权限。主窗口清理仅针对扫描时列出的具体文件，目录本身保留。保留空目录不会明显占用空间。

Windows 更新缓存只展示，不在工具中直接删除。点“Windows 存储设置”，在系统“临时文件/清理建议”中选择 Windows 更新相关项目。不要因此勾选仍要保留的“下载”或“回收站”。系统更新、微信、开发工具持续生成缓存是正常现象，建议每 1～3 个月检查一次。

扫描会跳过重解析点以防跨盘重复和误删；部分系统目录因权限原因不可读。列表不是完整磁盘容量核算，大小为逻辑长度，可能与实际释放空间不同。快速扫描只覆盖规则列出的常见目录。凭据目录、常见密钥文件和工具自身文件不允许清理；保护规则不能识别任意自定义名称的秘密文件。

最近一次扫描保存在 `%LOCALAPPDATA%\DiskReview\reports\latest-scan.json`，每次清理日志也保存在该目录。日志记录本地文件路径、大小、操作和结果。导出的清单不能直接作为删除脚本使用，每次打开都需重新扫描。

## 应用数据、缓存和后台占用

点主窗口顶部“应用数据 / 占用”，再点“扫描应用占用”。统计来源包括常见应用数据目录、AppData 中其他应用目录和 Windows 卸载注册表中的安装路径；注册表只读取应用名称和安装位置，不读取应用凭据。没有统一机制能发现每个应用自定义到任意位置的全部资料，因此结果会明确保留“未识别应用数据”和扫描限制，不声称覆盖所有文件。

展开一个应用，查看程序、数据、缓存和资源所在目录。缓存子目录已经包含在该应用总量中，不重复相加。迁移目录按实际位置统计一次，详情保留原入口。未能扫描的目录会标记大小不完整。根目录中的链接只用于定位实际位置；回收时不会穿过目录内部的链接。

- **程序 / 程序与数据混合目录**：不可勾选，使用“应用卸载”打开 Windows 已安装应用页面。独立且可靠识别的缓存子目录可单独处理。
- **应用数据 / 聊天资料 / 下载资料 / 模型或工具链**：显示用途和影响，由你手动勾选回收。整目录回收包含所有近期文件，不使用主窗口的“保留最近 7 天”。聊天记录、浏览器配置和离线资料可能不可重新下载；整目录操作会移走本地数据，关闭应用还可能写入最后状态。工具在回收前重新检查目录，确认范围是所选完整目录。
- **未知归属 / Microsoft Store 应用包 / 扫描不完整 / Codex 工具自身目录**：只统计，不在此直接回收。应用包通过 Windows 应用设置管理。模型、工具链、下载源码或已安装程序内部名称为 cache 的子目录不会仅凭名称开放清理。
- **移到回收站**：不主动关闭应用，文件仍被使用时可能失败。
- **关闭后台进程后回收**：先展示全部目标目录、进程名称、PID 和程序路径。勾选确认框后，先请求退出这些精确匹配的进程，2 秒后仍未退出的会强制结束；未保存的内容可能丢失。匹配根据程序所在目录及进程创建时间，不因同名就结束其他进程。不关闭系统服务、不提升权限；无法识别的占用、权限不足或新启动的后台进程仍可能导致回收失败。不会因此永久删除。

所有目录回收均使用 Windows 回收站接口，成功后要清空回收站才实际释放空间。选中父目录及其缓存子目录时只处理父目录一次。取消确认不会结束进程、不会删除文件；进行中停止会在当前操作完成后生效，已关闭进程或已回收项目不会自动撤销。

应用扫描清单和操作日志也保存在上述用户数据目录。应用窗口中的回收方式固定为回收站，不受主窗口永久清理方式影响。

## 验证

```
py -3 -B -m unittest discover -s tests -v
py -3 -B -m py_compile app.py core.py app_inventory.py app_view.py platform_paths.py windows_ops.py space_audit.py space_view.py
py -3 app.py --scan quick
py -3 app.py --scan apps --output summary.json
```

测试仅在专门建立的临时测试目录和新建的测试进程中进行，不清理用户数据、不关闭用户应用。集成回收测试会在回收站留下少量标为 DiskReview/test 的测试文件。代码均使用标准库。

命令行 `--root` 可以重复指定本地目录或磁盘。`--scan` 只读，不会清理文件。默认导出匿名汇总；`--include-private-paths` 会写入完整路径，请勿直接公开。
